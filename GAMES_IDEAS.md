# Идеи новых игр для Party in Pocket

## Контекст

Приложение работает в формате **«один телефон на всю компанию»**: команды/игроки по очереди берут устройство. Уже реализована «Шляпа» (3 раунда, таймер, паки слов, ИИ-генерация). В roadmap из README + закомментированные маршруты в `Screen.kt` упомянуты алиас, крокодил, шпион, данетки, мафия.

Сильные стороны платформы, под которые подбирались идеи:
- **ИИ-генерация контента** (`WordGenerationService`, OpenRouter) — отлично подходит играм со словами, вопросами, ситуациями.
- **Готовые компоненты**: `Team` со счётом по раундам, `WordPack`, таймер с фазами (`HatGamePhase`), система пропусков.
- **Формат «один телефон»** — игра не должна требовать персональных экранов (Шпион — пограничный случай).

## Часть 1. Игры, которые уже в первоначальном списке (с рекомендациями)

### 1. Алиас
**Геймплей**: команды объясняют словами на время, угадывают одной командой максимум слов. Победитель — команда с наибольшим счётом за N раундов или до порога (например, 50 очков).

**Рекомендации по реализации**:
- **Переиспользуй из Hat почти всё**: `Team` с очками, таймер, `WordPack`, `HatGamePhase` (READY → PLAYING → TURN_ENDED → GAME_FINISHED). Алиас = Шляпа без раундов с разными правилами.
- **Уникальная фишка** — *запретные слова* (как в коробочной версии): для каждого слова — 3-5 запрещённых ассоциаций. Промт для ИИ: «сгенерируй 30 слов на тему X, для каждого 4 запрещённых слова, которые нельзя произносить». Расширь `WordPack` или сделай отдельный `AliasWordPack`.
- **Условие победы**: настройка «играть до N очков» vs «играть N раундов» — выбор в `AliasSettings`.
- **Скоринг**: +1 за угаданное, -1 за пропуск (опц.) — переиспользуй `skipPenalty` из Hat.

**Что добавить нового**: модель «слово + список запрещённых», экран хода с показом запрещённых, проверка условия победы (а не «слова кончились»).

### 2. Крокодил
**Геймплей**: один игрок показывает слово жестами без звуков, остальные угадывают. Очко угадавшему и показывающему.

**Рекомендации по реализации**:
- **Это по сути 2-й раунд Шляпы (PANTOMIME)** — большая часть кода уже есть. Нужен лёгкий «standalone» режим без 3 раундов.
- **Без команд** (классический вариант) — индивидуальный счёт. Можно опционально включить «командный режим» в настройках.
- **Категории сложности**: ИИ-промт «лёгкие слова для крокодила» / «сложные» / «фразы» / «известные личности». Просто менять `temperature` и тему — паки складывать в отдельную секцию.
- **Минимальный UI**: экран показа слова → кнопка «угадали» (счёт + следующий ход) / «пропустить» (без штрафа или со штрафом).
- **Можно добавить таймер** (опционально) — игроки часто играют без него, но он добавляет драйв.

**Что добавить нового**: индивидуальный скоринг (без `Team`), экран выбора показывающего (или просто очередь).

### 3. Шпион
**Геймплей**: все игроки кроме одного знают локацию. Шпион должен её угадать, не выдав себя. Игроки задают друг другу вопросы про локацию, пытаясь вычислить шпиона.

**Рекомендации по реализации**:
- **Самая сложная из трёх** — нужна **скрытая раздача ролей** через передачу телефона. Это пограничный случай для «один телефон на компанию», но реализуемо.
- **Поток раздачи ролей**: экран «Передайте телефон Игроку 1» → тап «Я готов» → показ локации (или «Ты шпион») → тап «Скрыть» → передача следующему. Защита от подглядывания соседа (заставка-скрывалка после тапа).
- **Шпион видит только «Ты шпион»** + список возможных локаций (чтобы был шанс угадать).
- **Локации**: ИИ-генерация по темам («городские», «фэнтезийные», «офисные»). Каждая локация = 1 слово + опц. список ролей внутри неё (классическая версия даёт роли «бармен», «гость», «менеджер» в локации «бар» — добавляет глубины).
- **Фаза обсуждения**: таймер 6-10 минут (настраивается). По окончании — голосование: все указывают на подозреваемого. Если угадали шпиона — победа мирных, если нет — победа шпиона. Шпион может «сдаться» досрочно и угадать локацию.
- **Передача телефона** — главный UX-челлендж: продумай защиту от случайного просмотра (затемнение экрана между ходами).

**Что добавить нового**: режим скрытой раздачи (последовательность экранов с передачей), модель `SpyLocation` (название + опц. роли), фаза голосования.

## Часть 2. Дополнительные идеи

Отсортированы по близости к существующей механике Hat (легче переиспользовать код) → к независимым форматам.

### Игры со словами (родственники «Шляпы»)

**4. Контакт**
Ведущий загадывает слово и называет первую букву. Игроки придумывают определения к словам на эту букву и **синхронно** называют их вслух — если совпало, ведущий открывает следующую букву.
- **Почему подходит**: переиспользует `WordPack`, ИИ-генерация по темам.
- **Что нужно нового**: механика синхронного «контакта» (обратный отсчёт 3-2-1 на экране), скрытый показ слова ведущему.

**5. Кто я? (стикеры на лоб)**
Телефон поднимается ко лбу, на экране — слово (личность, предмет, профессия). Игрок задаёт «да/нет» вопросы, остальные кивают. Цель — угадать кто ты.
- **Почему подходит**: ИИ генерирует темы (актёры, мемы, исторические фигуры). Минимум UI.
- **Что нужно нового**: жесты (наклон вперёд = «верно», назад = «пропуск») — через сенсоры Android.

**6. Just One (одна подсказка)**
Все игроки пишут по одному слову-подсказке к загаданному. **Повторяющиеся подсказки вычёркиваются**. Угадывающий видит только уникальные.
- **Почему подходит**: одно устройство = идеально, ввод подсказок по очереди.
- **Что нужно нового**: режим скрытого ввода (передача телефона), детектор повторов (нормализация регистра/окончаний).

**7. Codenames (Кодовые имена)**
Две команды, сетка 5×5 слов, ведущие дают однословные подсказки + число. Цель — угадать слова своей команды, не задеть «убийцу».
- **Почему подходит**: переиспользует `WordPack`, `Team`. Топ-игра жанра.
- **Что нужно нового**: сетка 5×5, разделение видимости ведущие/игроки.

### Социальные

**8. Две правды и ложь**
Игрок диктует 3 утверждения о себе — 2 правда и 1 ложь. Остальные голосуют. Очки за угаданное и за обманутых.
- **Почему подходит**: ИИ может подкидывать **темы** для утверждений («про детство», «про путешествия»).
- **Что нужно нового**: ввод текста игроком, фаза голосования.

**9. Никогда я не**
ИИ генерирует утверждения «Никогда я не…», игроки опускают палец / тапают на свой аватар, если делали. Уровни «мягкий / средний / hardcore 18+».
- **Почему подходит**: чисто на ИИ-генерации, минимум UI.
- **Что нужно нового**: фильтр уровня в промте, простой UI с галерейкой утверждений.

**10. Бункер**
Сценарий апокалипсиса. Каждому — карточка (профессия, возраст, здоровье, скилл, хобби). Группа решает, кого выкинуть. Раунды откровений.
- **Почему подходит**: ИИ генерирует сценарии и характеристики. Длинная партия — для затяжных вечеров.
- **Что нужно нового**: генератор персонажей с атрибутами, экран «личная карточка» с передачей.

### Логика и дедукция

**11. Данетки**
Детективная загадка — игроки задают вопросы, ведущий отвечает «да/нет/неважно». Цель — раскрыть сценарий.
- **Почему подходит**: ИИ идеально генерирует загадку + спрятанный ответ. Паки по жанрам: детективы, мистика, абсурд.
- **Что нужно нового**: режим «ведущий видит ответ, остальные — только загадку».

**12. Wavelength (Длина волны)**
Команда видит шкалу с двумя крайностями («горячо ↔ холодно»). Ведущий видит точку на шкале и даёт подсказку одним словом. Команда двигает стрелку.
- **Почему подходит**: ИИ генерирует пары антонимов. Очень тематично для пати.
- **Что нужно нового**: визуальный спектр (Compose Canvas), таймер обсуждения.

### Творческие

**13. Чепуха (Mad Libs)**
Каждый игрок пишет фразу-продолжение, **не зная** что писали до него. В конце — зачитывание абсурдной истории.
- **Почему подходит**: ИИ задаёт шаблоны («Жил-был ___, он любил ___, но однажды ___»).
- **Что нужно нового**: режим скрытого ввода с передачей, экран финального зачитывания.

**14. История по словам (Story Cubes)**
Игрок получает 5-9 случайных слов и за 30 секунд сочиняет историю, используя все. Остальные слушают/голосуют.
- **Почему подходит**: ИИ генерирует контрастные наборы («дракон, чайник, тёща»). Простая механика.
- **Что нужно нового**: таймер, опциональное голосование.

### Знания

**15. Викторина**
ИИ генерирует пакеты вопросов по выбранной теме (история, кино, мемы, наука). Команды отвечают по очереди.
- **Почему подходит**: гибкость ИИ = бесконечный контент. Можно делать «личные» темы.
- **Что нужно нового**: проверка ответов (4 варианта или текстовый ввод с нечётким сравнением), таблица команд.

## Что я бы рекомендовал делать в первую очередь

**Самые простые** (максимум переиспользования Hat):
1. **Крокодил** — это по сути 2-й раунд Шляпы как отдельная игра. Очень быстро.
2. **Алиас** — Шляпа без раундов + опционально «запретные слова».

**Самые яркие** (большая ценность за умеренное усилие):
3. **Данетки** — flagship для ИИ-генерации: один промт → готовая загадка с ответом. Уникально.
4. **Кто я?** — простая в реализации, очень «мобильная» игра.
5. **Wavelength** — выделяется визуально, нет аналогов в русскоязычных приложениях.

**Сложные, но эффектные** (для второй итерации):
6. **Шпион** — сложен из-за скрытой раздачи ролей. Сделать после Кто я? (отработать передачу телефона).
7. **Codenames** — сложен из-за UX с двумя ролями за одним экраном.
8. **Бункер** — долгая партия, нужны генерация атрибутов и фаза обсуждения.
